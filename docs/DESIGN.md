# Europe Service — дизайн-система «Реєстр»

Мета: сайт має виглядати як солідна установа з власним характером — **не** як Personal Work (круглі картки, блакитний, «квитки/табло») і **не** як шаблон «згенерований ШІ» (центровані герої з пігулками, градієнтні плями, іконки в кольорових кружечках, однакові картки з тінями).

## Принципи
1. **Документ, а не вітрина.** Реквізити, ставки, телефони, дати, номери — моно-шрифтом (`font-mono` / клас `num`). Підписи розділів — `eyebrow` (моно, капітель, «01 — Назва»).
2. **Гострі кути.** Радіуси 0–6 px. Жодних `rounded-full` на кнопках, тегах, картках (лише аватар-кружечок, якщо треба). Не використовуйте `rounded-[22px]`, `rounded-3xl` тощо.
3. **Волосяні лінії замість тіней.** `border border-line`, `border-b border-line`, `divide-y`; акцентна лінія зверху блоку — `border-t-[3px] border-ink`; градієнтна лінія — `<div className="rule-grad" />`. Тінь лише `shadow-[var(--shadow-lift)]` для плаваючих панелей/модалок.
4. **Списки-реєстри замість сіток карток.** Рядки з тонкими розділювачами (як `VacancyCard`, список країн на головній, офіси в `OfficeTeam`).
5. **Корпоративний градієнт великими площинами**: `brand-band` (зелений → бірюзовий → блакитний, з тонкою сіткою). На ньому головна кнопка автоматично біла (`btn-accent`), другорядна — `btn-ghost` (біла рамка).
6. **Типографіка.** H1/H2 — `font-display` (Unbounded, вже за замовчуванням для h1/h2), H3 і текст — Golos (за замовчуванням). Великі цифри — `font-display` або `num`. Розмір тексту ≥ 15–16 px (аудиторія 40+, телефони).
7. **Без «зуму» на телефонах**: жодних hover/active scale; інпути ≥ 16 px.

## Токени (src/app/globals.css)
- Кольори: `ink` #0f241b (основний текст, темні кнопки), `ink-2`, `muted`, `line` (волосинка), `line-strong`, `surface` (#eef2ec, сіро-м’ятний фон секцій), `cream` (#f6f7f2, фон сторінки), `paper`/white (панелі), `brand-50…800` (зелені; кнопки — `brand-600`), `leaf` #5ec58a і `sky` #578fc7 (кінці градієнта логотипа), `night` (темний футер/смужка), `sun` (зірки).
- Утиліти: `container-x`, `brand-band`, `grad-text`, `rule-grad`, `eyebrow`, `num`, `btn`, `btn-accent` (головна, зелена), `btn-primary`/`btn-dark` (темна), `btn-ghost` (рамка), `btn-white`, `chip` (квадратний тег/фільтр), `card` (біла панель з рамкою), `field` (поле вводу), `label`, `prose-pw` (текст статей).

## Заборонено
- Метафори Personal Work: «квиток», «посадковий талон», «пасажир», «напрямок» як у квитку, табло вильотів, перфорація (`ticket-perf`), «маршрут» як тема дизайну.
- Емодзі-прапори як оформлення (замість них — двобуквений код країни моно-шрифтом на темній плашці).
- Фіолетові/помаранчеві акценти, неонові тіні, скляні ефекти, «плаваючі» іконки.
