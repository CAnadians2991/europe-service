# Адмінка Europe Service — коротка інструкція для менеджерів

Адреса: **europeservice.com.ua/admin** (пароль — у керівника; вхід пам'ятається 30 днів). Працює й з телефона.

## Нова вакансія за 1 хвилину
1. **Вакансії → «+ Нова вакансія»**.
2. Вставте текст вакансії так, як він є в Tilda, Telegram чи Viber (з емодзі й розділами) → **«Розпізнати»**.
3. Форма заповниться сама. Біля кожного поля — позначка: «розпізнано», «перевірте» або «не знайдено». Рядки, що не підійшли до жодного поля, показані окремо — допишіть їх у потрібний розділ.
4. Перевірте зарплату (цифри «від/до», нетто/брутто, валюта), країну, місто й категорію. Червоне попередження «нижче мінімальної ставки» — ставка, найімовірніше, застаріла.
5. SEO-заголовок, опис і адреса пропонуються автоматично. Адреса — як у Tilda: `/tpost/<код>-<назва-латиницею>`.
6. **«Зберегти»**. Якщо в тексті країна, якої ще немає на сайті, — кнопка «Додати країну» створить її одним натиском.

Адреса опублікованої вакансії **ніколи не змінюється** (на неї ведуть реклама й посилання). Закрита вакансія лишається на сайті з позначкою «набір закрито» — так було й у Tilda.

## Список вакансій
Фільтри: відкриті / закриті / Топ / усі, країна, пошук. Перемикачі «Активна» і «Топ» спрацьовують одразу. «Копія» — нова вакансія на основі наявної. Видалені потрапляють у кошик; кожна зміна зберігається в історії вакансії.

## Нова країна
**Країни** → почніть вводити назву → виберіть зі списку. Назви UA/RU, «в Австрії» / «в Австрии», код, адреса `/vacancies/<країна>` і SEO-тексти заповняться самі — перевірте за попереднім переглядом (як сторінка виглядатиме в Google) і збережіть. Видалити можна лише країну без вакансій (відкритих і закритих).

## Фото
- Перше фото — головне (картка в каталозі). Порядок — стрілками, «Зробити головним», ✕ — прибрати.
- Фото житла — **лише** в блок «Проживання» (не на обкладинку).
- Великі фото з телефона стискаються самі. HEIC з iPhone завантажуйте прямо з iPhone.

## Російська версія
Вкладка **«RU»**: «Скопіювати з української» → перекласти. З перекладом вакансія отримує сторінку `/ru/tpost/…`; без перекладу російська адреса веде на українську. Переклад **не оновлюється сам** — змінили ставку чи житло, виправте й тут.

## Тексти вакансій
Без обмежень за віком і статтю, без внутрішніх приміток для рекрутерів, без «роботи без оформлення». Тип договору — у кожній вакансії.

## Заявки, файли, «Про нас»
- **Заявки** — усі заявки з сайту (форма, вакансія, відповіді квізу).
- **Файли** — PDF/документи для посилань на сайті.
- **Про нас** — фото офісу й команди (менеджер, посада, Telegram/Viber). Публікуйте лише фото людей, які дали письмову згоду.
