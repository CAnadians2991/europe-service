# Перехід europeservice.com.ua з Тільди на новий сайт

Стан на 07.10.2026: новий сайт працює на https://europeservice-ua.netlify.app (Netlify, сайт `europeservice-ua`).

## Що перевірено перед переходом
- Усі **1972 адреси старого сайту** з sitemap і сторінок Тільди: 1939 відкриваються одразу, 25 — через одну 308-переадресацію на правильну сторінку, 404 немає, ланцюжків немає (`scripts/qa-crawl.mjs` + перевірка старих адрес).
- Усі сторінки нового sitemap (≈2400): статуси, title / description / H1 / canonical, hreflang UA↔RU (взаємні), биті посилання, відсутні картинки, «undefined» у тексті.
- Заявка з форми, заявка з квізу (месенджер і час доходять), замовлення в кошику — на живій базі; тестові записи видалено.
- Телефони 320–430 px: без горизонтального скролу, поля ≥16 px (iPhone не збільшує сторінку), потрібні клавіатури.
- Lighthouse (мобільний): швидкість 80–88, SEO 100, доступність 96–100, зсув верстки 0.

## Що потрібно до перемикання (блокери)
1. **Куди йдуть заявки.** Зараз — лише адмінка `/admin/leads`. Потрібен вхідний вебхук Бітрікс24 (`BITRIX_WEBHOOK_URL`) та/або Telegram-бот і чат (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`).
2. **Netlify: кредити / тариф.** У команди майже вичерпані кредити, автопоповнення вимкнене. Продакшн-трафік (сторінки, функції, картинки) потребує поповнення або тарифу з запасом — інакше сайт можуть призупинити.
3. **Доступ до Cloudflare** (DNS домену там) — у вашого адміністратора.

## Перемикання (≈15 хв, адміністратор Cloudflare + я)
1. Netlify → сайт `europeservice-ua` → Domain management → Add domain: `europeservice.com.ua`, потім `www.europeservice.com.ua` (основний — без www).
2. Cloudflare → DNS домену `europeservice.com.ua`:
   - видалити A та AAAA записи кореня (зараз ведуть на Тільду через проксі Cloudflare);
   - додати `CNAME @ → europeservice-ua.netlify.app`, **Proxy status: DNS only (сіра хмарка)**;
   - запис `www`: `CNAME www → europeservice-ua.netlify.app`, DNS only;
   - **MX (Google Workspace) і TXT не чіпати** — пошта працюватиме як і раніше.
3. Netlify сам випускає SSL-сертифікат (Let's Encrypt), коли DNS почне вказувати на нього (від кількох хвилин до години). Перевірити: https://europeservice.com.ua відкривається з замочком.
4. Netlify env: `PRIMARY_HOST=europeservice.com.ua` → новий деплой. Після цього `europeservice-ua.netlify.app` і `www` переадресовують на основний домен (код у `src/proxy.ts`).
5. Тільда → налаштування проєкту → домен: прибрати `europeservice.com.ua`, щоб Тільда не відповідала на нього. Експорт сайту з Тільди зберігається локально.

## Одразу після
- Повторити перевірку старих адрес і форм уже на домені.
- Google Search Console: власність залишається підтвердженою (той самий код у мета-тегу), надіслати `https://europeservice.com.ua/sitemap.xml`, перевірити кілька адрес через «Перевірка URL».
- Bing Webmaster — те саме; IndexNow на нашому домені вмикається автоматично.
- GTM / Google Ads / Meta / TikTok — ті самі ідентифікатори, конверсії `form_completion`, `purchase` продовжують працювати.
- Перші 3–7 днів: переглядати 404 у логах Netlify і помилки в Search Console.
