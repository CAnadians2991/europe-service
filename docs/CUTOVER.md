## Готовність (15.10.2026)

## Перемикання — лише Cloudflare (≈5 хв, адміністратор)
Cloudflare → домен `europeservice.com.ua` → DNS → Records:
1. Видалити записи **A** і **AAAA** для `europeservice.com.ua` (`@`) — вони ведуть на Тільду.
2. Додати **CNAME**: Name `@`, Target `apex-loadbalancer.netlify.com`, **Proxy status: DNS only (сіра хмарка)**, TTL Auto.
3. Запис `www` (зараз CNAME на `europeservice.com.ua`): змінити Target на `europeservice-ua.netlify.app`, **DNS only (сіра хмарка)**.
4. **MX, TXT (пошта Google Workspace, підтвердження Google) не чіпати.**

Після цього Netlify сам випускає SSL-сертифікат Let's Encrypt (зазвичай кілька хвилин, до години; поки його немає, https може показувати попередження). Перевірка: https://europeservice.com.ua відкривається з замочком, https://www.europeservice.com.ua переходить на основний домен.

Не обов'язково, можна будь-коли пізніше: Netlify env `PRIMARY_HOST=europeservice.com.ua` + деплой — тоді й `europeservice-ua.netlify.app` переадресовує на домен (зараз він закритий від індексації заголовком noindex, тож дублів у пошуку не буде). Домен у налаштуваннях проєкту Тільди можна прибрати — на трафік це вже не впливає.

Відкат: повернути в Cloudflare старі A/AAAA записи (Тільда досі опублікована).

## Одразу після
- Повторити перевірку старих адрес і форм уже на домені.
- Google Search Console: власність залишається підтвердженою (той самий код у мета-тегу), надіслати `https://europeservice.com.ua/sitemap.xml`, перевірити кілька адрес через «Перевірка URL».
- Bing Webmaster — те саме; IndexNow на нашому домені вмикається автоматично.
- GTM / Google Ads / Meta / TikTok — ті самі ідентифікатори, конверсії `form_completion`, `purchase` продовжують працювати.
- Перші 3–7 днів: переглядати 404 у логах Netlify і помилки в Search Console.
